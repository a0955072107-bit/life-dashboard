# TikTok 每週上傳流程（給 Claude 照做）

每週四 10:13（台灣時間），GitHub Actions「清醒行動派 TikTok 每週影片」會把下週日到週六的 7 支影片放到 Releases（tag `tiktok-<週日日期>`）。
週五 Yang 會收到提醒，然後在 Claude（Cowork，要接上 Chrome 擴充功能）開一個新對話，貼上：

> 照 https://github.com/a0955072107-bit/life-dashboard/blob/main/qingxing/tiktok/UPLOAD.md 排下週 TikTok

Claude 就照下面的步驟做。

## 規則

- 一定選「排程」，不要選「現在」發佈。
- 不刪除已經發佈的影片。
- 不輸入任何密碼或帳號資料。TikTok 沒登入就停下來，請 Yang 自己登入。
- 不改這個 repo。

## 1. 準備影片和文案（在雲端工作區做）

1. 範圍是下一個週日起 7 天。
2. 用 gh api（REST）列出 releases，找出含有這 7 天 `<日期>-DayNN.mp4` 的那一個。可能是較早、涵蓋好幾週的 release。
3. 把每天的 `.mp4` 和同名 `.txt`（文案）下載到工作區。
4. 文案如果還有「完整圖文在 IG @qingxing.action」，把那一行和後面的空行刪掉。
5. 草稿那天跳過，記下來最後回報。release 裡的 `manifest.json` 中，沒有 `file` 的那天就是草稿。

## 2. 先檢查重複

打開 https://www.tiktok.com/tiktokstudio/content 。已經排在某天「下午8:00」的，那天就跳過。

## 3. 每支影片（一次一支，確認好再做下一支）

1. **上傳**：打開 https://www.tiktok.com/tiktokstudio/upload ，用 find 找到 file input，再用 `file_upload` 傳 MP4（路徑用工作區的本機路徑），等上傳完成。
2. **文案**：說明欄是 Draft.js 編輯器，操作順序是：
   - 點一下 → ctrl+a → Delete → 打字輸入文案。
   - 打 hashtag 之前先等 2 秒。
   - 打完截圖，確認第一個 hashtag 沒有掉；掉了就把游標移到那裡補打。
3. **音樂**：
   - 按影片預覽旁邊的「音樂」，搜尋 `lofi`。主題是休息或整理時，改搜 `calm piano`。
   - 挑沒有人聲、輕柔的曲子，點那首的 +，再按右上角「儲存」。
   - 回到上傳頁，確認音樂有加進去。每天盡量換不同首，並記下曲名。
4. **排程**：
   - 發佈時間選「排程」，在日曆選當天，時間選 20:00。
   - 時間選擇器：點小時欄最下面一列會 +3，點分鐘欄最上面一列會 −15。邊點邊截圖確認。
   - 按「排程」之前截圖，確認選的是「排程」、日期和時間都對。
5. 按「排程」，等出現成功訊息。

遇到「離開網站？」的對話框，或分頁卡住，就開一個新分頁繼續。

## 4. 最後確認

回到 /content，確認每一支都排在正確日期的「下午8:00」。草稿那天除外。

## 5. 回報給 Yang（簡短）

- 排好了哪幾天：日期、標題、音樂名稱。
- 哪一天是草稿，所以沒排。
- 有沒有失敗的，失敗原因是什麼。
