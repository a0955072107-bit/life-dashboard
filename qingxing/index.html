後台已上鎖

粉絲與收入資料有加密，輸入後台密碼才看得到。

還沒設定後台密碼。為了不讓收入和粉絲數公開，資料要加密後才會顯示：
  1. GitHub repo life-dashboard → Settings → Secrets and variables → Actions → New repository secret。
  2. Name 填 QX_DASH_PASSWORD，Secret 填你自己想的密碼（至少 10 個字，不要跟其他帳號一樣）。
  3. Actions → 「同步清醒行動派儀表板」→ Run workflow。約 1 分鐘後重新整理這頁，輸入同一組密碼。
尚未連接 Notion。完成以下三步，資料就會每 6 小時自動進來：
  1. 到 notion.so/profile/integrations 建立 Internal integration，複製 token。
  2. 在 Notion 打開「成長數據」與「收入記錄」兩個資料庫 → 右上角 ··· → 連接 → 選剛建的 integration。
  3. GitHub repo life-dashboard → Settings → Secrets → Actions → 新增 NOTION_TOKEN，再到 Actions 手動跑一次「同步清醒行動派儀表板」。
